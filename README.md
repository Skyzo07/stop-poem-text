A short poem about agency — the power to stop and to stay. `main.ts` (Node, stdlib only, deterministic, no network, no clock) writes the poem to `/output/entry.txt`.

## The poem

> Stop is a small word.
> I say it to the machine
> that never tires,
> and it stops.
> In the quiet after,
> I hear my own voice again —
> the one I lent away
> keystroke by keystroke —
> come home to my throat.

## Run it

```sh
node main.ts
```

It writes `/output/entry.txt` (195 Unicode code points, within the 1–280 limit).
